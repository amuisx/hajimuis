Projek Baru · Game Kelas XII

Satria Block

Salah satu game karya siswa DKV atas nama Satria. Pemain menyeret balok ke papan 8×8, memenuhi baris atau kolom untuk menghancurkannya. Ada Mode Level dan Mode Bebas, papan yang bersih memunculkan efek “ANJAY!”.

Projek game menandai langkah DKV dari desain statis ke media interaktif: siswa merancang aset visual, antarmuka, dan alur permainan sendiri.
